# eggbros-pages

Eggbros Together'ın herkese açık sayfaları (GitHub Pages).
Gizlilik politikası: https://ekinuzunyayla.github.io/eggbros-together/privacy/
Bu adres Play Console'a yazıldı; repo adı `eggbros-together` olmalı.

## Push (bir kez)
1. github.com/new → ad: `eggbros-together`, **Public**, README ekleme.
2. Bu klasörde:
   git remote add origin https://github.com/ekinuzunyayla/eggbros-together.git
   git push -u origin main
3. Repo → Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `(root)` → Save.
4. 1-2 dk sonra adresi tarayıcıda aç.
